# 曲线立交的占地控制与交互验收 / Land controls for curved interchanges

调研日期：2026-10-25。范围：需求设计，不是已实现能力、实际工程认证或游戏兼容结论。所有下列运行验收仍为 NOT_RUN。只借鉴作者公开工作流，不复制代码；“placemarker”暂按用户所指为 CS2 Placemaker 理解。

## 1. 证据及可借鉴边界

- [Placemaker 作者 README](https://github.com/jackwrichards/placemaker)：确认“选区域—选内容—预览—Build”的工作流，作者标记 early access。可借鉴意图驱动、先预览后执行；不能据此声称其有立交求解器或与本项目兼容。
- [Network Tools 作者 README](https://github.com/lucarager/CS2-NetworkTools)：交互 3D 控柄、侧栏参数、实时预览；列出曲线、坡度、连接工具。可借鉴同一参数可拖拽也可数值修改、平面与纵断面联合检查；不作为必装依赖或已验证 API。
- [Placemaker issue #1](https://github.com/jackwrichards/placemaker/issues/1)：用户报告数值调节跳到最大/最小，要求直接输入数值或百分比。转化为可精确编辑、有单位、有上下界解释、撤销的验收；不是自行复现的故障结论。
- [Placemaker issue #12](https://github.com/jackwrichards/placemaker/issues/12)：用户报告生成区阻碍路侧修改，评论请求建成后手工修改。转化为预览区不能永久占有整块用地、对象级所有权、可解除生成器管理；不是已复现问题。
- [FHWA Interchange Design Promptlist](https://highways.dot.gov/field-offices/missouri/interchange-design-promptlist)：要求比较配置变体、适应地形/场地限制、检查方向性交通需求及路线连续性、交织、坡度和视距。仅为历史工程检查框架；不采用其数值作为游戏硬约束。

## 2. 硬边界优先：需求建议

| ID | 要求 / Requirement | 验收边界 |
|---|---|---|
| LAND-01 | 占地不是“城市/郊区”二选一。提供紧凑 Compact、均衡 Balanced、展开少堆叠 Spread / lower stacking、自定义 Custom。 | 预设只改明确列出的优化偏好；切换前后同一必需 OD、车道分配、通行方向、锁定道路、碰撞设置不变。所谓郊区不保证地形宽松，城区也不必然加层。 |
| LAND-02 | 地块由用户画允许多边形，支持禁建/保留洞；允许地块与禁止修改对象分开。 | 无效自交、多边形未闭合、洞越界明确提示；不得静默修补导致范围扩大。道路中心线在边界内不等于合格，要检查完整道路/结构/施工影响包络，未知包络不能绿灯。 |
| LAND-03 | 区分“完全禁入”与“地面保护但许可跨越”。第一阶段可只支持完全禁入。 | 跨越权限必须显式选择，默认不得把公园/河道的禁建区理解为可放桥墩。桥墩及基础位置、净空无法验证时标 UNKNOWN，不以空中投影替代地面检查。 |
| LAND-04 | 数值硬上限独立：最大面积 Maximum area、最大堆叠层数 Max stacked levels、最大高度 Max height；坡度/净空/道路功能另列。 | 层数指局部垂向叠层，不是全场桥梁条数；高度同时注明参考地面或标高基准，不混淆道路高度、结构顶高、净空。所有定义先冻结再验收。 |
| LAND-05 | 走廊锁 Corridor locks：保留主线形状/高程、保留节点/进出口、限制可修改弧长区间。 | 锁定目标 ID 与版本可见；锁定与面积冲突时说明冲突，不随意拉直既有两曲线或搬动邻接道路。不得将锁定等同于锁死一切匝道接入机会。 |
| LAND-06 | 优先选择正确曲线交会，再调占地。 | 高亮两条真实曲线及其局部切线、候选交会；多次交会要求明确选中一个处理区域。近切/近平行/重叠不强行生成标准四象限模板；方位标注用入口/出口和走廊名，不只用东西南北。 |
| LAND-07 | 匝道顺主线曲线接入，预览锚点沿弧长移动，不是水平/垂直平移。 | 拖动锚点后同时更新车道连接、完整路宽包络、纵坡与相交点净空；不得仅美化中心线而不重算路边缘和节点。超出支持域明确拒绝。 |
| LAND-08 | 同时显示硬约束与软偏好；滑条配直接输入和单位、键盘操作、恢复默认、撤销。 | 每次修改能看旧值→新值、哪些指标/约束受影响；非法输入不截断成一个用户没确认的值。交互过程中旧预览应标“过期/计算中”，避免错把旧结果作为新参数可行解。 |
| LAND-09 | 候选按紧凑、均衡、低堆叠比较，目标最多展示三种有实质差异的可行候选。 | 不承诺必有三种；仅一解显示一解，无解显示诊断。不可行草案可以单独查看但不得混入绿色可建候选；不得为了三张卡复制同一解。 |
| LAND-10 | 卡片必须展示同口径面积、局部层数、最大相对高度、最大坡度、匝道长度、必需流向/车道满足情况、交织风险。 | 交通容量、排队时间、成本、帧率只在实际测量或有明确模型时显示；否则 UNKNOWN / 未测。不能把主观综合分包装成“不会堵车”。 |
| LAND-11 | 面积和比例透明，叠层不能重复计为投影占地，外接矩形不冒充占地。 | 区分总道路投影并集、净新增占地、地面实占、改造影响区；选择一个明确指标施加面积硬限制，其余仍显示。比例必须注明分母是扣除禁区后的允许地块还是别的范围。m²/ha（1 ha=10,000 m²），显示单位切换不改变底层几何；不能以游戏格数替代未确认的实际尺寸。 |
| LAND-12 | 不可行解释“哪个约束与哪个需求冲突”，提供可比较的用户批准修改建议。 | 如“在当前面积及层数上限下未找到满足全部流向的解”；说明是求解器未找到解还是有证明的不可行。不得偷偷提高高度、减小净空、删掉出口、开启无碰撞、缩短必要渐变段。每个建议独立勾选后重新预览。 |
| LAND-13 | 参数可复现 Source parameters：保存输入几何/地形快照标识、地块与洞、走廊锁、必需流向、车道、规则版本、单位基准、求解器版本/种子/容差、依赖版本及所选候选。 | 分享风格预设不等于可复现工程实例。原路或地形已变时不可声称重载得到同一解；Apply 前重新核对并要求重新求解。语言切换不变参数和种子。 |
| LAND-14 | 占地与编辑所有权分离。 | 允许地块只是生成约束，不永久封锁整块地区的原生编辑；人工修改后可明确解除生成器管理，保护非本次创建对象。只“关闭自动重算”而仍重新覆盖对象不算解除。 |

## 3. 建议预览布局 / Preview structure

1. **选路和选交会**：两走廊、曲线交会候选、局部坐标方向、作用弧长区间。
2. **圈地与保留**：允许区、完全禁建洞、保留对象、可修改边界。图例与纹理辅助颜色，色盲可读。
3. **意图与硬边界**：三种偏好按钮；面积、层数、高度上限显示锁图标；车道及 OD 需求固定可见。
4. **三个候选（若存在）**：同尺度俯视缩略图、同角度 3D、可切纵断面；不让自动缩放掩盖真实占地差异。
5. **诊断与提交**：选中问题会定位到对应边界、桥下、坡段或车道节点；显示证据级别“几何预检通过 / 游戏未测”，不是笼统“完全兼容”。

“紧凑程度”单滑条可以作为入口，但必须展开实际改变的目标权重/软目标；不能一根滑条同时暗改面积、层数和功能而无解释。建议先固定硬约束，按已找到的非支配可行候选选择，而不是许诺连续滑动一定有连续解。

## 4. 必须加入的验收场景（均 NOT_RUN）

| 场景 | 预期 |
|---|---|
| 同样两条斜交曲线，宽松地块，用户优先低堆叠 | 可选择较展开方案（如有）；显示其真实面积代价，不保证总长度必然更短或交通必然更好。 |
| 同一输入改为紧凑城区边界 | 同 OD/同车道对比，地块内完整包络有效；不存在“为显示成功偷删一个转向”。 |
| 同时收紧面积、层数和高度直到无可行候选 | 明确无法找到可行解及原因/搜索局限；原存档不变，不自动开无碰撞。 |
| 弯曲窄长地块与 L 形地块，总面积相同 | 不当作等价可用空间；短边宽度、局部包络与连接路径决定是否可行，面积达标不代表地块内可放。 |
| 地块中有保留公园洞，既有道路绕洞 | 禁入洞完整保护；允许地块不能变成一张全场不可编辑的占有区域。 |
| 两曲线有两个交会点，选第二点 | 高亮正确交会及影响区，后续占地参数变化不跳到第一个点。 |
| 主线一段处于坡地，平面可放但净空/纵坡不满足 | 3D 诊断阻止提交，不用二维绿色蒙混；未知地形、结构下缘信息显式 UNKNOWN。 |
| 6→4+2 与全互通需求固定，切换偏好、语言及单位 | 车道语义和 OD 集合不变；UI 翻译/单位只影响显示，面积换算不改变解。 |
| 参数保存重载，输入及版本完全相同；然后只修改地形 | 前者在确定性约定内可复现；后者标 stale 并重算，不能静默复用旧净空。 |
| 允许地块最大面积一致，分别显示实际包络/外接矩形 | 面积卡片与选定指标一一对应；候选缩略图保持同尺度；不能通过改变统计口径得到“缩小占地”。 |

## 5. 需要实现阶段核验，不提前假定

- 道路/桥墩/地形改造完整包络能否从当前游戏数据准确读出，以及实时预览更新时延。
- Road Builder 道路变更后尺寸/车道连接更新；Anarchy 的存在只改变环境诊断，不能成为合法几何证明。
- 允许/禁建区域的多边形编辑成本和离散化容差；不能引用本调研随意设定“推荐多少平方米/多少层”。
- 何种布局类型在现有支持域内可解，何种为延期；不是承诺任意两条曲线/任意地形都能得到无损立交。
