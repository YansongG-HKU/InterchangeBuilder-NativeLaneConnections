## InterchangeBuilder Native Lane Connections 2.5.0

本版本把端点选择从固定的“左/中/右宽度偏移”升级为实际车道端口，并修复偏移连接生成后被误回滚的问题。

### 全车道端点

- 从游戏原生面板选择输出道路，起点道路不会覆盖选择。
- 读取新道路默认车道与既有道路实时 composition，按位置和实际行驶方向匹配。
- 支持任意单向、双向、奇偶车道、非对称、公交专用及 Road Builder 等自定义道路。
- 中心和游戏原生宽度/8 米分区格候选永远保留；车道数据可用时会补充全部完整车道窗口。
- 起点和终点独立选择，中文面板在点击前显示新路车道与既有路车道对应关系。

### 生成安全

- 偏移端点产生新侧向节点时，按路线几何走廊和图连通性识别完整永久道路链。
- 归属匹配超时时不再删除游戏已经生成的永久道路，并显示保留数量。
- 可选通过反射登记 Anarchy 的 `InterchangeBuilder.Curve` 工具并显示真实开关；不硬依赖、不捆绑、不自动切换。

### 验证

- 29 项核心测试覆盖 1–10 车道全部单向组合、2→4、2→8、端点方向、非对称、双向车道、元数据回退、偏移六段链恢复和断链拒绝。
- 当前游戏程序集下运行时目标检查通过。
- 构建流程验证简体中文 UI JavaScript 语法和完整运行包元数据。
