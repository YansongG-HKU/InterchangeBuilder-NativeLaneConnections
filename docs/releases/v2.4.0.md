## InterchangeBuilder Native Lane Connections 2.4.0

本版本删除 2.3.0 的“待确认 / 已锁定 / 跟随起点”交互，改为完全跟随游戏原生道路面板。

### 新的道路选择方式

1. 在游戏原生道路面板选择道路。
2. 打开立交道路生成器并选择建造模式。
3. 模组自动记住该道路；选择起点和终点不会改变道路类型。
4. 需要换路时，直接在游戏原生道路面板点击另一条道路即可。

模组面板只读显示当前道路。切换道路会清除旧预览，避免旧几何与新道路宽度不一致。

### 兼容范围

- 原版道路、步道和轨道。
- 能被游戏原生 `NetToolSystem` 与 InterchangeBuilder 识别的自定义网络。
- 曲线、直线、S 弯、U 形、回旋、自由绘制、环岛和平行道路等创建道路的模式。
- 平整道路与节点编辑不创建新道路，因此不要求道路选择。

### 验证

- 17 项核心算法和道路选择记忆测试。
- 游戏运行时补丁签名与原生 `NetToolSystem` 字段检查。
- 简体中文 UI 语法、安装包完整性以及不包含游戏程序集检查。
