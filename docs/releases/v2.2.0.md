## InterchangeBuilder Native Lane Connections 2.2.0

首个可直接安装的公开版本，提供《城市：天际线 II》原生风格的道路端点车道对齐、简体中文 UI 和道路规则提示。

主要变化：

- 宽度不一致的道路支持鼠标选择左、中、右对齐，中心候选始终保留。
- 同时覆盖 8 米分区格吸附和自由宽度对齐逻辑。
- 支持游戏原生连接兼容性过滤和多臂节点方向选择。
- 预览中选择的对齐会一直保留到最终放置。
- 12 项核心测试通过，运行时冒烟检查覆盖 7 个 Harmony 目标。

### 直接安装

1. 下载 `InterchangeBuilder-2.2.0-NativeLaneConnections.zip`。
2. 退出游戏，将 ZIP 解压到 `%USERPROFILE%\AppData\LocalLow\Colossal Order\Cities Skylines II\Mods`。
3. 在 Skyve II 中禁用订阅版 InterchangeBuilder（153013），启用本地 2.2.0 版本；不要同时加载两个副本。
4. 通过 Skyve II 或 Steam 启动游戏。

发布包已经包含运行所需的 InterchangeBuilder 1.4.2 文件，不需要自行编译。原版文件依据仓库维护者确认取得的 TheJof 再分发许可提供，仍保持原权利归属；发布包不包含任何《城市：天际线 II》游戏程序集。SHA-256 校验值随 ZIP 一并提供。
