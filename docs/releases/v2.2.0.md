## InterchangeBuilder Native Lane Connections 2.2.0

首个公开源码版本，提供《城市：天际线 II》原生风格的道路端点车道对齐、简体中文 UI 和道路规则提示。

主要变化：

- 宽度不一致的道路支持鼠标选择左、中、右对齐，中心候选始终保留。
- 同时覆盖 8 米分区格吸附和自由宽度对齐逻辑。
- 支持游戏原生连接兼容性过滤和多臂节点方向选择。
- 预览中选择的对齐会一直保留到最终放置。
- 12 项核心测试通过，运行时冒烟检查覆盖 7 个 Harmony 目标。

由于原版 InterchangeBuilder 未随附允许再分发其文件的许可证，本 Release 只提供本升级层的源码归档，不附带原模组或游戏二进制。请自行取得 InterchangeBuilder 1.4.2（Paradox Mods ID 153013），按仓库 README 构建完整本地测试包。
