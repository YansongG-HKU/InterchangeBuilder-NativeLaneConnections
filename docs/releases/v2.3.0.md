## InterchangeBuilder Native Lane Connections 2.3.0

本版本修复道路面板选择会被起点道路静默覆盖的问题，并保留 2.2.0 的原生端点和车道对齐能力。

### 新增

- 输出道路分为“待确认”“已锁定”“跟随起点”三种明确状态。
- 面板分别显示最终输出道路与起点来源道路。
- 手动锁定后，选择起点只决定连接分支、方向和端点位置，不会替换道路类型。
- 更换道路时自动清除旧预览；未确认道路时阻止最终建造。
- 建造日志记录选择模式、输出 prefab 和起点来源，便于复查。

### 安装

1. 下载 `InterchangeBuilder-2.3.0-NativeLaneConnections.zip`。
2. 解压到《城市：天际线 II》的本地 `Mods` 目录。
3. 在 Skyve II 中只启用本地 2.3.0，禁用其他 InterchangeBuilder 版本。
4. 启动游戏，在道路列表选择道路后点击“确认并锁定”。

### 验证

- 17 项核心算法和道路选择状态机测试通过。
- 运行时目标签名、补丁程序集、中文 UI JavaScript 和完整安装目录构建通过。
