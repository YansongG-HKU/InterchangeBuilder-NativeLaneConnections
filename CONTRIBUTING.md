# Contributing / 贡献

Use this repository for both Mod and offline-lab development. Start with [the document index](docs/DOCUMENTATION_INDEX.md), [integration scope](docs/INTEGRATION.md) and [approved left-turn plan](docs/LEFT_TURN_PLAN.md). Follow [AGENTS](AGENTS.md) and scoped lab instructions. / 后续只维护本仓，不在源仓继续新功能。

Keep changes reversible, use Draft PRs, report independent expected/actual/version evidence and all unrun gates, and review the whole documentation set. Existing PR #3/#4 are unmerged proposals, not automatically accepted dependencies. No merge/release without authorization. / 全仓文档同步，未验证不写通过。

Root runtime and imported lab rights differ; see [license scope](docs/INTEGRATION.md). No third-party code copying or game/private payloads. Runtime builds need separately supplied lawful game/base-package dependencies; offline tests do not establish runtime compatibility.
